# ジェノグラム・エコマップ作成アプリ

ケアマネジメント・ソーシャルワークの現場で使う「ジェノグラム（家族構成図）」と「エコマップ（支援ネットワーク図）」を、ブラウザだけでサクッと作れる無料ツールです。

**公開URL：** https://kat-t00.github.io/genogram-app/

インストール・会員登録・ダウンロードは一切不要。リンクを開けばすぐ使えます。

---

## 主な機能

### ジェノグラム（家族構成図）
- 父母・配偶者・子・兄弟姉妹などを選んで追加するだけで、結婚線・親子の樹形図を自動で描画
- 「基準にする人」を本人以外（子・兄弟など）に変更すれば、**子の配偶者・孫・義父母・おじ・おば**なども正しい世代に配置して描ける
- 同居家族は自動で点線の枠に囲まれる
- 故人（死亡）には×印、キーパーソンには★マークを表示
- 結婚線をクリックすると「別居（斜線1本）」「離婚（斜線2本）」のマークを付けられる
- 「📋 同じ構成で複製」で、似た人物（兄弟・孫など）をすぐ横に追加できる

### エコマップ（支援ネットワーク図）
- 関係機関・地域の人などを登録し、本人・家族とのつながり（強い関係・弱い関係・対立・一方向の働きかけなど）を線で表現
- 任意のメンバーを選んで枠線で囲む「グループ化」機能（拡大家族・職場など）
- 同居している世帯全体や、グループの枠線そのものに関係機関をつなぐことも可能

### 共通機能
- ジェノグラムのみ／エコマップのみ／両方の表示切り替え
- ドラッグでの手動位置調整（自動レイアウトと両立、手動調整は保持される）
- 元に戻す／やり直す（Undo/Redo）
- 画像（PNG）・PDF出力（透明背景・モノクロ対応、PDFは横向き／縦向き選択可）
- PDF出力には凡例・作成日・作成者名も同梱可能
- 複数事例をブラウザに自動保存、ファイルへの書き出し・読み込みにも対応

---

## 動作環境

- 対応ブラウザ：Chrome / Edge / Safari などの最新ブラウザ
- サーバー不要、データは基本的にお使いの端末（ブラウザ）内に保存されます
- 個人情報を含むデータを外部に送信する機能はありません（完全にブラウザ内で動作）

---

## 使い方

1. 公開URLを開く
2. 「✨ はじめから作成」で本人の名前を入力してスタート
3. 「👪 家族追加」「🏢 関係機関登録」から構成員を追加
4. 必要に応じて「🔍 全体表示」「🧹 整頓」で見やすく調整
5. 「📄 PDF出力」または「🖼 画像出力」で書き出し

画面右上の「❓ ジェノグラム・エコマップとは？」「📘 使い方ガイド」に、操作方法と凡例の説明をまとめています。

---

## 既知の制限

- 本人が複数回結婚している場合（再婚等）、結婚線は簡易的な表示になります（誰がどちらの結婚の子かまでは厳密に描き分けていません）
